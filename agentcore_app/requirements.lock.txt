# Exact transitive lock for the container image: every version resolved into
# the build that was validated end-to-end against the deployed runtime.
#
# The Dockerfile installs from THIS file, not requirements.txt, for two
# reasons. Reproducibility is the obvious one — this agent's behaviour depends
# on how strands-agents drives tool execution and Nova Sonic, and an unpinned
# resolve has already shipped a break (BidiAudioInputEvent gaining required
# fields, which killed a call the moment the caller spoke). The other is build
# time: pinning only the direct dependencies leaves pip reconciling three
# packages' overlapping botocore ranges, and it backtracks through hundreds of
# releases — 270+ downloads and still going. A complete lock resolves flat.
#
# requirements.txt stays the human-facing declaration: edit that, then
# regenerate this from it (no Dockerfile change needed, same base image):
#
#   docker run --rm --platform linux/arm64 -v "$PWD:/w" -w /w \
#     public.ecr.aws/docker/library/python:3.13-slim sh -c '
#       apt-get update -qq && apt-get install -y -qq gcc python3-dev \
#         portaudio19-dev libasound-dev >/dev/null 2>&1 &&
#       pip install -q --upgrade pip setuptools wheel &&
#       pip install -q -r requirements.txt &&
#       pip freeze | grep -viE "^(pip|setuptools|wheel)=="' > requirements.lock.txt
#
# Two pins here are deliberate DOWNGRADES, and the image does not work without
# them: protobuf 7.36.1 -> 6.33.5 and cachetools 7.1.8 -> 6.2.4. Both are
# demanded exactly by aws-opentelemetry-distro==0.19.0, which is what the
# Dockerfile's `opentelemetry-instrument` CMD needs; installing the distro
# against the older pins' successors is ResolutionImpossible. Nothing else in
# this graph objects — every protobuf requirer accepts >=6.33.5,<8.0.0, and
# py-key-value-aio is the only package that wants cachetools at all (>=5.0.0) —
# and `pip check` reports no broken requirements on the result. If a future
# resolve drags either back up, the distro will fall out and the Dockerfile CMD
# has to return to plain uvicorn in the same change, or tracing stops silently.
#
# The opentelemetry-instrumentation-* set at 0.65b0 is the distro's own
# dependency closure. Most of it is for frameworks this app never imports
# (django, celery, kafka, …) and costs only image size; the ones that earn their
# place are fastapi, botocore, urllib3, httpx and requests — those are the spans
# the in-process setup never produced.
#
# Sphinx and its extensions are in here because strands-agents[bidi-all]
# declares them as real dependencies, not because anything builds docs.
