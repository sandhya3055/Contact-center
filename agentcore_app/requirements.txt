aws-opentelemetry-distro==0.19.0  # the ADOT distro behind `opentelemetry-instrument` (see the
                            # Dockerfile CMD). Brings the auto-instrumentation the wrapper activates —
                            # FastAPI, botocore, urllib3 — so a trace carries the request and the AWS
                            # calls, not just the spans Strands emits for itself.
                            # This release pins its whole dependency set exactly, and two of those
                            # pins are why the lock below moved: protobuf==6.33.5 (was 7.36.1) and
                            # cachetools==6.2.4 (was 7.1.8). Both are downgrades, and both are safe
                            # against the rest of the graph — every protobuf requirer here accepts
                            # >=6.33.5,<8.0.0, and py-key-value-aio is the only thing that wants
                            # cachetools at all (>=5.0.0). Installing 0.19.0 without moving them is
                            # ResolutionImpossible, so this and the lock have to change together.
                            # It also pins api/sdk 1.44.0 and the instrumentation 0.65b0, which is
                            # what the lock already held. An older distro (0.13.0) instead drags
                            # opentelemetry-proto back to a release whose protobuf range has no
                            # candidate here, and the resolve fails outright rather than degrading.
python-dotenv==1.2.3        # loads ../.env for local dev only (no-op in the deployed container)

                            # Pinned: 0.2.14 is the version already verified to build cleanly (used by
